# SOP: Opportunity management (EMEA)

| | |
|---|---|
| Owner | Sales Operations EMEA |
| Applies to | All sales reps, regional leads and FAEs in EMEA |
| Review | Quarterly |
| Version | 1.0 (sample) |

## 1. Purpose

Keep every module opportunity in the CRM accurate enough to forecast from. One rule: **if it is not in the CRM, it did not happen.**

## 2. When to create an opportunity

Create one opportunity **per module family per customer project**.

- A smart meter that uses an LTE-M module and a GNSS module is **one project with two opportunities**.
- Do not create an opportunity for general interest without a device project. Keep that as a lead.

## 3. Step by step

1. **Check for duplicates.** Search the account by name *and* web domain before creating anything.
2. **Create or select the Project** on the account: device name, application, vertical, target launch date.
3. **Create the Opportunity** from the project. Fill in:
   - Module family
   - Annual units (best estimate, update later)
   - Average selling price (from the quote, or the list price if no quote yet)
   - Project life in years
   - Expected close date (the date you expect the **design-win**, not the first shipment)
   - Next action and next action date
4. **Move stages only when exit criteria are met** (see the stage table below).
5. **Update at least every 30 days**, even if nothing changed. Write "No change, customer testing until 15 Nov" in the next action.
6. **Close lost opportunities** with a loss reason. Lost data is as valuable as won data.

## 4. Stage exit criteria

| Stage | Probability | Move on when |
|---|---|---|
| Lead | 5% | Use case, contact and rough volume known |
| Qualified | 10% | Project created, launch date and annual volume estimated |
| Sample / Evaluation | 20% | Samples or EVB shipped and logged, FAE assigned |
| Design-in | 40% | Module in the customer design, quote accepted in principle |
| Design-win | 70% | Written confirmation or BOM lock, ramp plan known |
| Pilot | 85% | Pilot PO received, certification passed |
| Mass production | 100% | Recurring orders, tracked as shipments |

## 5. Forecast categories

Set the forecast category yourself. The stage probability is a cross-check, not a replacement.

- **Commit:** 90% or higher confidence for this period. You are accountable for it.
- **Best case:** possible this period, risks named in the record.
- **Pipeline:** not this period.

## 6. Data quality checks (run every Monday)

| Check | Fix within |
|---|---|
| Missing next action | 5 working days |
| Missing annual units | 5 working days |
| Missing vertical | 5 working days |
| Close date in the past | Before forecast close |
| No update for 30+ days | 5 working days |
| Possible duplicate | Sales Ops merges within 10 working days |

Open after 5 working days: the regional lead is copied. After 10 working days: Sales Director review.

## 7. Help

Questions about the process or a record you cannot fix: contact Sales Operations EMEA.
